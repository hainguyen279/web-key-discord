# SHARK Key Portal

Cấu trúc tách module:

- `index.html` — markup/giao diện
- `assets/css/style.css` — toàn bộ CSS và animation
- `assets/js/config.js` — cấu hình Ouo.io + tên storage
- `assets/js/app.js` — hiệu ứng không gian, Ouo gate, Key, modal, copy

## Cấu hình
Mở `assets/js/config.js` và thay:

`https://ouo.io/PUT-YOUR-LINK-HERE`

bằng link Ouo.io của bạn.

## Chạy
Upload toàn bộ thư mục giữ nguyên cấu trúc, sau đó mở `index.html` hoặc domain của bạn.
